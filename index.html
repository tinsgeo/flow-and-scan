Practice pulling operations data

This site simulates two kinds of operational data you'll find inside almost any warehouse, fulfillment, or manufacturing environment. Use it to practice the skills from The VBA Portfolio Project — reading what's on screen, then pulling it into Excel with VBA.

Nothing here is real operational data. Every number is generated for practice — on the visual dashboards it changes each time you load the page or click "Regenerate," and on the plain data tables it refreshes on a fixed schedule so there's always something new to pull.

Two views, two purposes

Visual dashboards

Productivity and Order Flow are built to be looked at — filter, click into an associate's scan history, watch the order counters move. This is the "see the problem" half of the skill.

Data sources — easy and hard mode

Real websites usually don't hand you a plain table. Most render their data with JavaScript into <div> elements, which a basic VBA web query can't read at all — it only ever sees the raw HTML a server sends, before any script runs. This site gives you both versions to practice on.

Easy mode — plain tables

/data/associates.html and /data/orders.html are plain <table> HTML, no JavaScript. Point Excel's "Data > From Web" or a VBA QueryTables web query straight at these and the data comes right in.

Hard mode — JavaScript-rendered divs

/data-hard/associates.html and /data-hard/orders.html look similar but render entirely with JavaScript into styled <div> rows, and keep refreshing on their own. A plain web query returns an empty shell here — this is where you practice the technique in the book for pulling data out of pages that don't cooperate.

Where to start

If you're working through Chapter 3, start with the easy-mode associates table — loop through it, calculate the gap between each scan for a given ID using DateDiff, and flag anything 15 minutes or more, the same as the idle-time tracker. Once that works, try the same exercise against hard mode using the technique from later in Chapter 4.

If you're working through Chapter 4, start with the easy-mode orders table, then try hard mode once you've read the section on pulling data out of JavaScript-rendered pages.
